### Установка

Добавить в `tailwind.config.js`, созданный в пакете `tailwindcss-theme`.

    "./vendor/4geo35/product-favorite/src/resources/views/components/**/*.blade.php",
    "./vendor/4geo35/product-favorite/src/resources/views/web/**/*.blade.php",
    "./vendor/4geo35/product-favorite/src/resources/views/livewire/web/**/*.blade.php",

#### Views

Сокращение для представлений: `pf` 

#### Livewire Components

- `pf-switch-favorite`
- `pf-ico-favorite`
- `pf-list-favorite`

#### Config

Название файла: `product-favorite`

- `useBreadcrumbs` => `true`
- `useH1` => `true`
- `favoritePageTitle` => `Избранное`
